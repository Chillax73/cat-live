# 金渐层大作战

电脑浏览器里的轻量猫咪生存小游戏。大头短腿的金渐层自动挥爪，空格飞扑，吃小鱼干升级，守住自己的客厅。

## 运行

需要 Node.js 22 或以上版本。没有第三方依赖，不需要安装包或配置环境变量。

```sh
npm run dev
```

打开 http://127.0.0.1:4173。服务仅监听本机；在启动服务的终端按 Ctrl+C 停止。

```sh
npm run dev -- --port 4174  # 指定其他端口
npm test                   # 核心规则与存档测试
npm run build              # 生成静态 dist/
npm run preview            # 预览 dist/，同样使用 4173
```

dev 和 preview 使用同一个默认端口，先停止已有服务再启动另一个。若服务器运行于受限沙箱，需要允许本机监听端口。

## 怎么玩

- WASD / 方向键：移动；静止时保持最后朝向。
- 空格：沿移动或最后朝向扑击，短暂无敌且能造成伤害；冷却结束再次使用。
- 猫爪自动攻击，走过去吃鱼干积累经验；升级暂停后三选一，数字 1/2/3 也能选择。
- Esc：暂停/继续。升级中按 Esc 可打开暂停菜单，继续后回到原来的三选一。
- 开局有悠闲猫、标准猫、猛猫三档，默认标准；暂停时可降低本局难度。
- 5:00 暴走吸尘器入场，击败即获胜；大招有地面预警。生命归零失败，可以立即重开。
- 音乐和音效分别调整，设为 0 即静音。窗口失焦/页面隐藏后暂停，回来手动继续。

技能、生命和经验每局重置。浏览器只保存设置和各难度最好成绩，关闭页面不保存未结束的局；禁用浏览器存储仍能游玩。

## 当前范围

V1 包含一张客厅、三种普通敌人、吸尘器 Boss、八种成长技能、猫咪动作和打击反馈、声音、暂停、难度、存档与结算。家具为装饰，可以穿过。所有美术与声音由代码生成，无远程资源。

「失败后积累资源、永久培养猫咪」明确列入 V2，本版不提供跨局属性成长。推荐桌面宽窗口与键盘；窄窗口保持可读，暂不提供手机触摸操作。

# 金渐层大作战 · 需求规格

状态：V1 实现依据；更新日期：2026-10-13。

## 目标与用户

面向使用电脑浏览器、喜欢猫咪和生存动作游戏的玩家。借鉴幸存者类的自动攻击与随机成长，突出大头短腿金渐层的动作、表情和性格。核心体验是「猫的动作讨喜、扑击好用、攻击有爽感，失败后愿意再玩一局」。

## 已确认的需求

- 电脑浏览器、单人、2D 游戏卡通画风；可爱且战斗爽快。
- 主角为大头短腿金渐层，强调移动、挥爪、扑击、吃鱼干、炸毛和舔爪的表现。
- WASD 或方向键移动，自动攻击；空格朝当前移动方向扑击，静止时沿最后朝向扑击。
- 拾取小鱼干获得经验；升级时暂停，提供三项技能，选完恢复。
- 默认有挑战但不苛刻，支持难度调整。
- 每局独立成长。失败积累资源、永久培养猫咪明确属于 V2。

## V1 实现范围与默认方案

以下为讨论中的建议落地值，可在试玩后调整。

1. 一张暖色客厅地图。家具作为场景装饰，不阻挡移动；房间边界限制角色位置。
2. 约六分钟一局：普通敌人逐渐增多，5:00 吸尘器 Boss 入场；击败 Boss 胜利。未击败时继续战斗，6:00 后普通敌人不再加速增长。
3. 三种普通敌人：追击扫地机器人、预警后直线冲撞的玩具车、远程投射毛球的捣蛋玩具。Boss 有预警冲撞和扇形投射攻击。
4. 猫爪自动攻击附近敌人，击退并播放爪痕；扑击期间无敌、穿过敌人造成伤害，冷却结束有提示。
5. 升级围绕猫爪、扑击、炸毛、呼噜恢复、肉垫护体、拾取范围与移动速度。三选一随机、无重复，描述明确；满级技能退出候选池，全满后提供即刻恢复。
6. 悠闲猫、标准猫、猛猫三档。调整数量、组合、速度、伤害和预警节奏，不堆叠普通敌人血量。开局自由选择；局内暂停只允许降档，实际难度显示于结算。
7. 受伤后短暂无敌，敌人偶尔掉落回血零食；升级选择和暂停期间所有游戏计时冻结。
8. 开始界面、HUD、升级、暂停、胜利/失败结算、一键重开。Esc 暂停/继续，数字 1/2/3 选择升级。
9. 分别调节音乐和音效音量，提供静音；轻快合成背景音乐、攻击、扑击、拾取和猫叫音效。
10. 浏览器保存难度、音量、各档最好成绩；存储不可用时仍能正常游玩。不同局的技能和角色数值不延续。
11. 切换标签页或窗口失焦自动暂停，恢复焦点不自动继续；关闭当前页面不保留未结束的局。

## 非目标与下一版

V1 不含移动端触屏控制、登录、后端、多人、排行榜、在线通信、广告、付费、永久属性或资源积累。

V2：失败后积累跨局资源，永久培养金渐层。届时另行确定资源用途、成长上限与难度平衡；配饰解锁、更多地图也可作为后续候选，不是 V1 验收条件。

## 边界与非功能要求

- 主要面向现代桌面 Chrome/Edge/Safari/Firefox，推荐窗口宽度 ≥ 900px；小窗口提供键盘提示并保持界面可读。
- 输入不触发页面滚动；对角移动归一化。切出窗口清除按键，避免角色持续移动。
- Web Audio 在用户交互后启动；不支持音频时静默降级，不影响战斗。
- 使用固定步长模拟、限制敌人和粒子数量，避免窗口恢复后大步长补算。视觉抖动遵循减少动态效果偏好。
- 无远程字体、图像、网络数据或运行时第三方依赖。没有环境变量或凭据。
- 技能、难度、计时和结算用 HTML 呈现，支持键盘选择和可见焦点。

## 验收标准

| ID | 可验证行为 |
| --- | --- |
| A1 | 本地启动后能选择三档难度并开始游戏，无页面脚本错误 |
| A2 | WASD/方向键正常移动、对角速度一致；空格有定向伤害和冷却，无页面滚动 |
| A3 | 敌人自动追击/冲撞/射击，猫爪自动攻击；击败敌人掉落可拾取经验 |
| A4 | 升级暂停且出现三个不同有效选项，选择后数值生效并继续；跨多级不丢失经验 |
| A5 | 受伤无敌、回血、零血失败、Boss 入场和击败胜利均生效 |
| A6 | Esc/按钮/窗口切换暂停所有模拟；暂停可降档，不能升档 |
| A7 | 音量与难度重载后保持，成绩按难度保存；存储损坏/不可用不阻断游玩 |
| A8 | 结算可重开，新局时间、经验和技能全部重置 |
| A9 | 浏览器实际检查开始、战斗、升级、暂停、结算和窄窗口布局；核心规则通过自动化验证 |
| A10 | README 含运行、构建、测试命令；SPEC/DESIGN/PLAN 记录实际交付和已知限制 |

无待澄清的阻断项。数值和长时间游玩的主观难度仍需玩家试玩反馈。
